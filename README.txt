AI LABORATORY - JAVA PRACTICALS

REQUIREMENT
- Install JDK (Java Development Kit).
- Open Command Prompt or VS Code Terminal in this folder.

COMPILE AND RUN ANY PROGRAM
1. Open terminal in this folder.
2. Compile:
       javac FileName.java
3. Run:
       java ClassName

Example:
       javac BFS.java
       java BFS

The file name and public class name are the same in every program.

INPUT NOTES
- A* 8-puzzle: enter numbers 0 to 8 exactly once; 0 is the blank.
- Alpha-Beta: enter 8 integer leaf values.
- Tower of Hanoi: enter a positive number of disks.
- Sudoku: enter 81 values row by row; use 0 for empty cells.
- BFS/DFS: vertices are numbered 0 to n-1; enter edges and start vertex.
- 8-Queens: no input required.
- Chatbot: type a message; type bye to stop.
- Number Guessing Agent: think of a number from 1 to 100; H means guess is too high,
  L means too low, C means correct.
- Blocks World: enter each stack bottom-to-top as a string, e.g. AB means B is on A.
  Initial and goal states must contain the same blocks.
- Minimax: play as X; computer plays as O; choose cells 1 to 9.
